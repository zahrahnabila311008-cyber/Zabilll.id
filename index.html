Pendahuluan: Kabel LAN / Ethernet

Kabel LAN (Local Area Network) atau sering disebut kabel Ethernet/UTP (Unshielded Twisted Pair) adalah media transmisi fisik berbentuk kabel yang digunakan untuk menghubungkan berbagai perangkat komputer (komputer, laptop, router, switch) dalam lingkup jaringan lokal. Kabel ini berfungsi untuk mentransfer data digital dalam bentuk sinyal elektrik dengan kecepatan tinggi dan tingkat kestabilan yang lebih baik dibandingkan jaringan nirkabel (Wi-Fi).

Alat & Bahan Pembuatan Kabel LAN

Kabel UTP (Cat5e / Cat6)

Kabel berpasangan terpilin yang berfungsi sebagai media penghantar arus data jaringan.

Konektor RJ-45

Konektor standar berpin 8 yang dipasang di kedua ujung kabel UTP.

Tang Crimp (Crimping Tool)

Alat khusus untuk mengupas kabel, memotong, dan mengepres konektor RJ-45.

LAN Tester

Alat penguji untuk memastikan semua urutan kabel terhubung sempurna.

Pembuatan Kabel Tipe Crossover (Cross)

Kabel tipe **Crossover** digunakan untuk menghubungkan dua perangkat sejenis (peer-to-peer) secara langsung, seperti **Laptop ke Laptop**.

Langkah Pembuatan:

  1. Kupas jaket luar kabel UTP sepanjang ± 2 cm menggunakan tang crimp.
  2. Uraikan pilinan kabel dan luruskan tiap helai kawat.
  3. Susun urutan warna kabel sesuai standar **T568A** pada ujung pertama, dan standar **T568B** pada ujung kedua.
  4. Ratakan ujung kawat dengan memotongnya secara presisi menggunakan cutter tang crimp.
  5. Masukkan urutan kawat ke dalam konektor RJ-45 hingga menyentuh pin tembaga di ujung konektor.
  6. Masukkan konektor ke lubang tang crimp lalu tekan kuat-kuat hingga terdengar bunyi "klik".
  7. Uji kedua ujung kabel menggunakan **LAN Tester**. Untuk kabel Cross, lampu indikator akan menyala menyilang (1-3, 2-6, 3-1, dst).

Menghubungkan 2 Laptop & Sharing File

1. Pengaturan IP Address Static

Hubungkan kedua laptop menggunakan kabel Cross, lalu lakukan konfigurasi IP pada masing-masing laptop:

  • Buka Control Panel > Network and Sharing Center > Change Adapter Settings.
  • Klik kanan pada Ethernet > Properties > Dobel klik IPv4.
  • Laptop A: IP Address: 192.168.1.1 | Subnet Mask: 255.255.255.0
  • Laptop B: IP Address: 192.168.1.2 | Subnet Mask: 255.255.255.0

2. Pengecekan Koneksi (Ping Test)

Untuk memastikan kedua laptop sudah saling terhubung:

  • Buka Command Prompt (cmd) pada Laptop A.
  • Ketik perintah: ping 192.168.1.2 lalu tekan Enter.
  • Jika muncul balasan "Reply from 192.168.1.2: bytes=32 time<1ms TTL=128", berarti laptop berhasil terhubung.

3. Cara Transfer File (Sharing File)

  1. Klik kanan pada folder yang ingin dibagikan > pilih Give access to > Specific people...
  2. Pilih Everyone dari daftar dropdown, klik Add, lalu ubah Permission Level menjadi Read/Write. Klik tombol Share.
  3. Pada laptop penerima, buka File Explorer dan ketikkan IP laptop pengirim pada address bar: \\192.168.1.1.
  4. Folder yang di-share akan muncul dan file dapat diakses atau disalin secara langsung!
